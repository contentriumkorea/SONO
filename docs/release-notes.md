SONO 0.1.9 — A–B 구간 반복

- 재생바 A–B 버튼에서 시작 A와 종료 B를 지정해 해당 구간 반복
- 시간 직접 입력과 ‘현재 위치를 A/B로’ 버튼 지원
- 파형에 반복 구간과 A/B 지점 표시, 반복 범위 안에서 탐색
- 일시정지/다시 재생 지원; 반복 중에는 다음 곡이나 대기열로 넘어가지 않음
- ‘구간 반복 해제’로 원래 재생 방식 복귀
- 음원 길이를 조정한 곡에서도 지정 구간 안에서 반복
- 다른 곡으로 이동, 음원 길이 변경, 앱 재실행 시 구간 반복 해제

구간은 0.1초 이상으로 지정해주세요. 음원 원본과 기존 길이 조정 설정은 유지됩니다.

0.1.3 이상 설치 사용자는 앱의 ‘업데이트 → 지금 업데이트’로 설치할 수 있습니다.
Mac 앱은 DMG에서 응용프로그램 폴더로 옮겨 실행해주세요.
Mac은 ad-hoc 서명을 사용하는 시험 배포이며 Developer ID 서명·공증은 아직 구성하지 않았습니다.
