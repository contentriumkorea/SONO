SONO 0.1.7 — 파형 오류 수정과 페이드 직접 입력

- 파형 캐시를 저장할 수 없는 경우에도 분석된 파형 표시
- 긴 AIFF/AIF 및 지원되는 PCM AIFC 음원의 파형 분석 추가 (파일 전체를 메모리에 올리지 않는 방식)
- 페이드 인·아웃의 초 표시를 더블클릭해 0–5초 값을 직접 입력
- Enter로 적용, 다른 곳을 클릭해 적용, Escape로 취소; 기존 슬라이더 유지
- 직접 입력한 페이드 값은 앱 재실행 후에도 유지

음원 원본 파일은 변경하지 않습니다. 모든 압축 AIFF 코덱을 지원하는 것은 아닙니다.

0.1.3 이상 설치 사용자는 앱의 ‘업데이트 → 지금 업데이트’로 설치할 수 있습니다.
Mac 앱은 DMG에서 응용프로그램 폴더로 옮겨 실행해주세요.
Mac은 ad-hoc 서명을 사용하는 시험 배포이며 Developer ID 서명·공증은 아직 구성하지 않았습니다.
