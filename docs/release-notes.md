SONO 0.1.5 — 긴 음원 파형 수정

- 1시간이 넘는 MP3, 128 MiB보다 큰 지원 음원에서도 파형 표시
- MP3·FLAC·M4A/AAC 등을 작은 구간씩 읽고 디코딩해 전체 음원 버퍼를 만들지 않음
- 분석 진행률과 읽은 구간의 파형을 순차적으로 표시
- 곡을 바꾸면 기존 분석을 취소하고 새 곡 분석 시작
- 분석 결과 캐시, 파형 탐색·일시정지·자동 업데이트 유지

디코딩할 수 없는 코덱은 기본 재생바를 유지합니다. 스트리밍을 지원하지 않는 형식은 짧은 음원에서 Web Audio 호환 분석을 사용합니다. 원본 파일은 변경하지 않습니다.

0.1.3 이상 설치 사용자는 앱의 ‘업데이트 → 지금 업데이트’로 설치할 수 있습니다.
Mac 앱은 DMG에서 응용프로그램 폴더로 옮겨 실행해주세요.
Mac은 ad-hoc 서명을 사용하는 시험 배포이며 Developer ID 서명·공증은 아직 구성하지 않았습니다.

파형 분석에 [Mediabunny 1.61.0](https://github.com/Vanilagy/mediabunny)을 사용합니다. MPL 2.0 라이선스와 정확한 버전의 원본 소스 안내는 앱의 resources/THIRD_PARTY_NOTICES.md에 포함되어 있습니다.
