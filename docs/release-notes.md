SONO 0.1.4 — 원하는 위치에 추가 · 음원 파형

- 외부 음원 파일·폴더를 곡 위·아래에 놓으면 해당 위치에 삽입
- 폴더 제목에 놓으면 해당 폴더에 추가, 빈 폴더도 지원
- 재생목록에도 원하는 위치에 파일 추가 가능
- 이미 가져온 파일을 다시 놓으면 중복 없이 위치 변경
- 위치에 추가한 뒤 ‘직접 정한 순서’로 전환하고 재실행 후 유지
- 재생바에 실제 음원을 분석한 파형 표시: 재생한 부분은 흰색, 남은 부분은 회색
- 파형 클릭·드래그·방향키로 재생 위치 이동
- 파형 캐시 저장·원본 변경 시 다시 분석, 긴 PCM WAV는 스트리밍 분석
- 기존 자동 업데이트·개별 삭제·페이드·폴더 이동 기능 유지

원본 음원 파일은 이동하거나 변경하지 않습니다.
WAV 외 디코딩은 Web Audio를 사용합니다. 디코딩할 수 없거나 128 MiB/1시간을 넘는 비-WAV 파일은 기본 재생바를 유지합니다. PCM WAV는 파일을 나누어 분석합니다.

0.1.3 설치 사용자는 앱의 ‘업데이트 → 지금 업데이트’로 설치할 수 있습니다.
Mac 0.1.2 이하에는 자동 교체 코드가 없어 최초 한 번 직접 앱을 교체해야 합니다.
Mac 앱은 DMG에서 응용프로그램 폴더로 옮겨 실행해주세요.
Mac은 ad-hoc 서명을 사용하는 시험 배포이며 Developer ID 서명·공증은 아직 구성하지 않았습니다.
