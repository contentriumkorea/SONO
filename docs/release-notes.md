MusicBoard 0.1.10 — 앱 이름 변경

- SONO의 새 이름은 MusicBoard(뮤직보드)입니다.
- 메인 화면·정보·업데이트·미니 플레이어·Mac 메뉴·설치 제품명·바로가기 이름 변경
- 새 설치 파일은 MusicBoard 이름으로 제공하며 기존 SONO 앱에서도 업데이트 가능
- 음악 목록·재생목록·표시 이름·설정·파형·구간 편집 데이터 유지

기존 설치 앱은 ‘업데이트 → 지금 업데이트’로 변경할 수 있습니다.
기존 Mac의 SONO.app 설치 경로와 내부 실행 파일명은 호환성을 위해 유지합니다. 앱 표시 이름은 MusicBoard입니다.
새 Mac 설치는 MusicBoard DMG에서 앱을 응용프로그램 폴더로 옮겨주세요.
SONO 이름의 배포 파일은 기존 앱 업데이트를 위한 호환 파일입니다.
Mac은 ad-hoc 서명을 사용하는 시험 배포이며 Developer ID 서명·공증은 아직 구성하지 않았습니다.
