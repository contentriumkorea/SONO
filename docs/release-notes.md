SONO 0.1.3 — 앱 안에서 자동 업데이트

- Windows·Mac: ‘업데이트’ 창을 열면 새 버전 확인
- ‘지금 업데이트’ 한 번으로 다운로드 → 보관함·설정 저장 → 앱 교체 → 재실행
- Mac: ZIP 크기·SHA-256, 앱 ID·버전·코드 서명 확인 후 교체
- Mac: 새 앱이 정상 실행되지 않으면 이전 앱으로 복구
- 기존 개별 삭제 및 설정 창의 삭제 단축키 보호 포함

Mac 0.1.2 이하에는 자동 교체 코드가 없어서 0.1.3으로 최초 한 번 직접 앱을 교체해야 합니다. 0.1.3부터 이후 버전은 앱 안에서 업데이트합니다.
Mac 앱은 DMG에서 응용프로그램 폴더로 옮겨 실행해주세요. 앱 폴더에 쓰기 권한이 있어야 합니다.
음악 원본·보관함·표시 이름·재생목록·설정은 유지됩니다.

설치 파일:
- Windows: `SONO-0.1.3-windows-x64-setup.exe`
- Mac (Apple Silicon / Intel 공용): `SONO-0.1.3-mac-universal.dmg`

Mac은 ad-hoc 서명을 사용하는 시험 배포이며 Developer ID 서명·공증은 아직 구성하지 않았습니다.
