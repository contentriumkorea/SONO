SONO 0.1.6 — 음원 길이 조정

- 곡의 ‘더 보기 → 음원 길이 조정’ 또는 재생바 가위 버튼으로 구간 편집
- 시작/종료 시간 입력, 슬라이더, 현재 위치를 시작/종료로 지정
- 지정 구간만 재생하고 구간 끝에서 다음 곡 자동 재생·한 곡 반복·현재 곡 후 정지 적용
- 목록 길이, 재생 시간, 탐색 범위와 파형을 지정 구간에 맞춰 표시
- 구간 설정 재실행 후 유지, ‘원래 길이’로 복원

음원 원본 파일은 변경하지 않습니다. 새 오디오 파일을 내보내는 기능은 포함하지 않습니다.

0.1.3 이상 설치 사용자는 앱의 ‘업데이트 → 지금 업데이트’로 설치할 수 있습니다.
Mac 앱은 DMG에서 응용프로그램 폴더로 옮겨 실행해주세요.
Mac은 ad-hoc 서명을 사용하는 시험 배포이며 Developer ID 서명·공증은 아직 구성하지 않았습니다.
