SONO — macOS와 Windows용 로컬 음악 플레이어

- 파일·폴더 가져오기, 폴더별 목록, 곡과 폴더 순서 변경
- 곡 이동·표시 이름 변경·다중 선택 삭제
- 페이드 인·아웃, 재생 방식 선택, EQ, 미니 플레이어
- 보관함·재생목록·설정 자동 저장
- 왼쪽 아래 업데이트 버튼에서 새 버전 확인

설치 파일:
- Windows: `SONO-…-windows-x64-setup.exe`
- Mac (Apple Silicon / Intel 공용): `SONO-…-mac-universal.dmg`

Windows 설치 버전은 앱 안에서 업데이트 다운로드 후 재시작하여 설치합니다.
첫 Mac 배포는 서명·공증 전 시험 배포입니다. 업데이트 버튼에서 새 설치 파일을 받아 앱을 교체합니다.
음악 파일과 보관함·설정은 업데이트 시 유지됩니다.
