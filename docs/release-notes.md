SONO 0.1.8 — 확장자가 다른 음원의 파형 수정

- MP3 이름으로 저장된 AAC/MP4 음원의 실제 형식과 길이를 읽도록 수정
- 파형 분석은 실제 오디오 타임라인의 길이를 기준으로 계산
- 기존 보관함의 해당 파일 정보 자동 갱신; 삭제하거나 다시 가져올 필요 없음
- 이전 버전에서 길이가 잘못 적용된 파형 캐시는 다시 계산
- 표시 이름·곡 순서·폴더·즐겨찾기·재생목록·설정 유지

음원 원본 파일의 이름이나 내용은 변경하지 않습니다.

0.1.3 이상 설치 사용자는 앱의 ‘업데이트 → 지금 업데이트’로 설치할 수 있습니다.
Mac 앱은 DMG에서 응용프로그램 폴더로 옮겨 실행해주세요.
Mac은 ad-hoc 서명을 사용하는 시험 배포이며 Developer ID 서명·공증은 아직 구성하지 않았습니다.
