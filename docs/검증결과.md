# MusicBoard 검증 결과

## 0.1.10 MusicBoard 이름 변경

- SONO → MusicBoard(뮤직보드): 메인 화면·정보·업데이트·미니 플레이어·기본 앨범 표시·HTML/네이티브 창·Mac 메뉴·설치 제품명·Windows 바로가기·배포 제목·현재 문서·실행 안내 변경. 960×650에서 긴 이름이 잘리지 않도록 브랜드 크기 조정.
- 기존 업데이트를 보존하기 위해 저장소 URL·앱 ID·Luma Music 데이터 경로·내부 SONO 실행 파일명 유지. 새 MusicBoard 설치 파일에 더해 실제 기존 SONO 앱이 요구하는 SONO-root Mac ZIP/DMG 및 Windows 설치 호환 파일 제공. 기존 Mac의 SONO.app 경로는 유지되며 새 설치 DMG는 MusicBoard.app을 사용합니다.
- 새 Mac 업데이터는 MusicBoard ZIP을 우선 사용하고 이전 SONO ZIP도 수용합니다. 고정 저장소 URL·버전·크기·SHA-256·단일 허용 앱 루트·실행 파일·앱 ID·서명 검증 유지. 잘못된 새 ZIP을 기존 이름으로 우회하지 않습니다.
- 업데이트 이름/보안 검사의 실패 3개를 확인한 뒤 구현. 읽기 전용 검토에서 Mac universal 합본의 afterPack 재호출 문제 1개를 발견하여 실패 검사로 재현 후 수정. 총 87개 단위 검사·타입 검사·빌드 통과. 기존 기능을 포함한 통합 스크립트 13개 통과.
- 개발 및 실제 Windows 0.1.10 패키지에서 네이티브/화면 이름·정보/업데이트/미니 창·작은 화면·이전 목록/설정 저장 확인. Windows 패키지의 업데이트 IPC·진행률·설치 호출도 검증했습니다(다운로드/설치 호출은 시뮬레이션).
- 첫 GitHub 실행은 Windows 전체와 Mac 설치/브랜드/실제 앱 교체 검사를 통과했으나, 실제 이전 버전 시험 파일의 메타데이터를 받는 GitHub API 요청이 실패해 공개를 중단했습니다. 해당 시험 요청에 CI의 기본 contents:read 토큰을 연결했고 앱 코드·검증 기준은 유지합니다.
- 사용자 개인 Mac 설치·오디오 출력 및 Windows 기존 설치본의 실제 설치 프로그램 교체는 직접 확인하지 않았습니다. 소개 웹사이트의 소스는 현재 프로젝트에 없어 외부 소개 카드 변경은 포함하지 않습니다.

## 0.1.9 A–B 구간 반복

- 재생바 A–B 버튼, 직접 시간 입력과 실제 현재 위치의 A/B 지정, 최소 0.1초·범위·순서 검사 및 파형 구간 표시 추가. 반복 범위 안에서 탐색하며, B 도달 시 A로 돌아가고 대기열/다음 곡으로 진행하지 않습니다.
- 일시정지·다시 재생, 반복 해제 후 저장된 재생 방식 복귀, 곡 전환·길이 편집·재실행 시 해제. 길이 편집 곡은 편집 시작점 기준으로 A/B를 입력하고 원본 좌표로 재생합니다. 원본 파일과 저장된 길이 편집 설정은 변경하지 않습니다.
- 엔진·입력 화면의 실패 검사를 먼저 확인한 뒤 구현. 파일 끝에서 반복을 재시작하는 순간 곡을 바꿀 때 발생하는 정상 AbortError를 재현하고 오류 표시를 수정했습니다. 총 83개 단위 검사·타입 검사·빌드 통과, 기존 기능을 포함한 통합 스크립트 12개 통과. 읽기 전용 검토에서 Critical/Important 문제 없음.
- 실제 PCM 음원으로 개발 앱에서 6개 A–B 통합 검사 통과: 입력 유효성·960×650 화면·파형 표시·범위 내 탐색·반복 재생 위치·종료 페이드 억제·대기열 보존·일시정지·해제·파일 끝 반복·곡 전환·편집 구간 상대 시간·현재 위치·재실행·원본 SHA-256 보존. 취소 오류 수정 뒤 단위/빌드와 A–B 통합 검사를 다시 통과했습니다.
- 실제 Windows 0.1.9 패키지에서도 동일한 A–B 통합 검사 6개와 원본 SHA-256 보존을 확인했습니다.
- GitHub Windows·Mac 각각 83개 단위 검사·타입 검사·설치 빌드 및 통합 검사 109개 PASS. 두 설치 앱의 A–B 구간 반복과 Mac 실제 앱 교체·재실행·설정 보존 통과: https://github.com/contentriumkorea/SONO/actions/runs/37282873907
- SONO 0.1.9 공개 완료, 설치 파일/업데이트 정보 8개 확인. Windows latest.yml 0.1.9 및 기존 Mac 업데이트 코드의 공개 ZIP URL·크기·SHA-256 수용 확인: https://github.com/contentriumkorea/SONO/releases/tag/v0.1.9
- HTMLAudioElement 탐색을 이용한 구간 반복이며 샘플 단위의 무간격 반복은 보장하지 않습니다. 개인 Mac의 오디오 출력은 직접 확인하지 않았습니다.

## 0.1.8 확장자와 실제 형식이 다른 음원의 파형

- 사용자 문제 원본에서 재현: 확장자는 MP3지만 실제 파일 헤더는 MP4(ftyp)·AAC이며, 확장자 기반 파서가 길이를 0.0426667초로 읽었습니다. 실제 길이는 209.908390초이고, 이전 파형은 960개 중 마지막 한 칸에만 모였습니다.
- 파일 기반 Blob의 지연 읽기·임의 위치 탐색으로 콘텐츠 기반 메타데이터 판별. 파형 계산은 오디오 패킷의 실제 길이 사용. 기존 보관함의 MP4 오표기 항목은 시작 시 12바이트 헤더 확인 후 정보 갱신하며 ID/이름/폴더/즐겨찾기/재생목록/설정은 보존합니다.
- 파형 캐시 버전 변경으로 이전에 잘못된 길이를 사용한 결과를 다시 계산합니다. 원본 파일의 이름이나 내용은 변경하지 않습니다.
- 새 실패 검사 3개를 확인한 뒤 수정. 총 78개 단위 검사·타입 검사·빌드 및 기존 기능을 포함한 통합 스크립트 11개 통과. 읽기 전용 검토에서 Critical/Important 문제 없음.
- 실제 사용자 원본을 격리된 Windows Electron 데이터로 검증: 기존 잘못된 정보/캐시 복구, 길이 209.908초, 948개 비영(非零) 파형 피크, 재생·탐색·재실행 보존·원본 SHA-256 동일 확인. 같은 잘못된 확장자의 합성 AAC/MP4(12.064초)도 검사했습니다.
- 실제 Windows 0.1.8 설치 패키지에서도 사용자 원본의 209.908초 정보 복구·전체 파형·재생·탐색·재실행·원본 SHA-256 보존을 확인했습니다. GitHub Windows·Mac 각각 78개 단위 검사·타입 검사·설치 빌드 및 통합 검사 97개 PASS. 두 설치 앱에서 오표기 형식의 합성 음원 자동 복구, Mac 실제 앱 교체·재실행·설정 보존 통과: https://github.com/contentriumkorea/SONO/actions/runs/37094112031
- SONO 0.1.8 공개 완료, 설치 파일/업데이트 정보 8개 확인. Windows latest.yml 0.1.8 및 기존 Mac 업데이트 코드의 공개 ZIP URL·크기·SHA-256 수용 확인: https://github.com/contentriumkorea/SONO/releases/tag/v0.1.8
- 원본 음원은 저장소/배포에 포함하지 않습니다. 사용자 개인 Mac의 원본 음원 재생과 실제 오디오 출력은 직접 확인하지 않았습니다.

## 0.1.7 파형 오류·페이드 직접 입력

- 캐시 디렉터리 생성/파일 저장 오류가 유효한 파형 표시를 중단하는 문제를 네이티브 WAV와 브라우저 디코딩 경로에서 재현하고 수정했습니다. 캐시 없이도 분석 결과를 표시합니다.
- 지원 목록에 있으나 스트리밍 분석이 없던 AIFF/AIF의 PCM 분석 추가. AIFF signed 8/16/24/32-bit 및 PCM AIFC NONE/twos/sowt/float 32/64-bit, 모든 채널 최대 진폭·SSND 오프셋·홀수 청크 패딩 처리. WAV와 공유하는 64 KiB 읽기 버퍼로 전체 음원을 메모리에 올리지 않습니다.
- 페이드 값 더블클릭 직접 입력, 0–5초 유효성 검사, Enter/포커스 이동 적용·Escape 취소·키보드 진입·기존 슬라이더·설정 재실행 유지 구현.
- 실패 검사를 먼저 확인한 뒤 수정. 로컬 74개 단위 검사·타입 검사·빌드, 기존 기능을 포함한 통합 스크립트 10개 통과. 별도 읽기 전용 코드 검토에서 Critical/Important 문제 없음.
- 실제 합성 음원과 차단된 캐시 경로를 사용해 WAV/FLAC/5011초 MP3 파형 표시, 4200초·128 MiB 초과 스테레오 AIFF의 무음/작은/큰 소리 피크, 직접 입력·취소·범위 검사·재실행 보존을 Electron에서 확인했습니다.
- 로컬 실제 Windows 0.1.7 패키지의 파형 오류 복구·페이드 직접 입력 검증 통과. GitHub Windows·Mac 각각 74개 단위 검사·타입 검사·설치 빌드 및 통합 검증 91개 PASS 확인. 두 설치 앱에서 이번 파형/입력 검사와 Mac의 실제 앱 교체·재실행·설정 보존 통과: https://github.com/contentriumkorea/SONO/actions/runs/37091517147
- SONO 0.1.7 공개 완료, 설치 파일/업데이트 정보 8개 확인. Windows latest.yml 0.1.7과 기존 Mac 업데이트 코드의 실제 ZIP URL·크기·SHA-256 수용 확인: https://github.com/contentriumkorea/SONO/releases/tag/v0.1.7
- 사용자 문제 파일은 아직 제공되지 않아 해당 파일의 해결 여부를 단정하지 않습니다. 압축 AIFF 코덱 전체 지원이나 AIFF 재생 엔진 변경은 포함하지 않습니다. 개인 Mac의 직접 설치·오디오 출력과도 구분합니다.

## 0.1.6 음원 길이 조정

- 곡별 시작/종료 시간 저장, 원본 구간 재생/복원, 유효성 검사와 시각적 편집 화면 추가. 종료 타이머·페이드·다음 곡/반복/정지, 복원 재생 위치, 미니 플레이어와 구간 파형/시간 표시 연결. 신뢰하는 원본 길이로 저장 범위 재검사.
- 구간 검증/시간 파싱/저장 및 엔진 시작/탐색/중복 종료 방지/일시정지 편집 회귀 검사의 실패를 먼저 확인한 뒤 구현. 총 63개 단위 검사·타입 검사·빌드 통과.
- 실제 합성 WAV로 개발 및 Windows 설치 앱에서 잘못된 입력·시간/슬라이더 편집·960×650 화면, 실제 구간 시작/탐색/자동 넘김/반복/정지, 일시정지 편집, 현재 위치·취소·중복 가져오기·재실행 보존·복원·원본 SHA-256 유지 검증 통과.
- 기존 통합 검증에서 발견된 추가 시각 밀리초 중복에 따른 최근 추가순 시험 가정을 화면의 실제 순서 기준 검증으로 교체. 제품 정렬 방식은 그대로 유지합니다.
- GitHub Windows·Mac 각각 63개 단위 검사·타입 검사·빌드와 통합 검사 79개 PASS 확인. 실제 두 설치 앱에서 구간 편집·재생·복원·저장·원본 SHA-256 보존, Mac 실제 자동 교체·재실행·설정 보존 통과: https://github.com/contentriumkorea/SONO/actions/runs/37089029998
- SONO 0.1.6 공개 완료, 설치 파일/업데이트 정보 8개 확인. Windows latest.yml 0.1.6과 기존 Mac 업데이트 코드의 실제 ZIP URL·크기·SHA-256 수용 확인: https://github.com/contentriumkorea/SONO/releases/tag/v0.1.6
- 앞서 보고된 특정 긴 음원의 파형 실패는 파일 정보가 없어 재현하지 못했습니다. 이 버전에서 그 문제가 해결됐다고 간주하지 않습니다.

## 0.1.5 긴 음원 파형

- 0.1.4의 1시간/128 MiB 차단을 지원 코덱의 구간 디코딩으로 교체. Mediabunny 입력 캐시 8 MiB, 한 번에 현재 디코딩 구간과 960개 피크만 유지. 진행률/부분 파형과 곡 변경 시 취소 추가.
- 이전 코드에서 길이·크기 회귀 검사 2개가 제한 오류로 실패하는 것을 확인한 뒤 새 코드에서 통과. 긴 타임라인의 스테레오/무음과 취소 검사 추가. 단위 검사 총 59개, 타입 검사·빌드 통과.

- 위 음원 검증은 로컬 개발 및 실제 Windows 0.1.5 패키지에서 모두 통과. 기존 삭제·드롭·이동·재생·업데이트를 포함한 통합 스크립트 8개 통과. 목록 대기와 드래그 핸들을 명시해 기존 재생목록 드래그 검사에서 발견한 타이밍 불안정도 수정.

- 실제 패키지 통합 검증: WAV 가져오기, 중복 제외, 재생 시간 진행, 일시정지, 탐색, 좋아요, 재생목록 생성/추가, 재생 대기열, EQ 조절, 미니 플레이어 조작, 취침 타이머 설정, 곡 종료 후 이동, 검색, 즉시 종료의 최종 위치 저장, 재실행 데이터 유지, 자동 재생 방지 통과.
- 초기 화면, EQ 화면 및 보관함을 1320×880 / 960×650 크기에서 확인.
- 테스트 음악과 데이터는 임시 폴더에 생성하고 검증 종료 후 제거했습니다. 실제 사용자 보관함에 예시 음악을 넣지 않았습니다.

미확인 항목: macOS 설치/실행/오디오 출력/미디어 키, WAV 외 코덱별 재생, 취침 타이머의 실제 15분 경과. 타이머 설정과 시간 계산은 구현되어 있으나 15분을 기다리는 검증은 수행하지 않았습니다.

macOS 공용 DMG/ZIP과 Windows NSIS 설치 파일을 GitHub Actions에서 빌드하여 v0.1.0 릴리스에 공개했습니다. Mac 실제 설치·실행·오디오 출력은 아직 확인하지 않았습니다.
