## 0.1.5 긴 음원 파형

- 0.1.4의 1시간/128 MiB 차단을 지원 코덱의 구간 디코딩으로 교체. Mediabunny 입력 캐시 8 MiB, 한 번에 현재 디코딩 구간과 960개 피크만 유지. 진행률/부분 파형과 곡 변경 시 취소 추가.
- 이전 코드에서 길이·크기 회귀 검사 2개가 제한 오류로 실패하는 것을 확인한 뒤 새 코드에서 통과. 긴 타임라인의 스테레오/무음과 취소 검사 추가. 단위 검사 총 59개, 타입 검사·빌드 통과.
- 실제 5011초 CBR MP3의 무음/작은 소리/큰 소리/마지막 무음, 전체 파일 디코딩 0회, Range 206 읽기, 진행률, 긴 구간 탐색·일시정지 확인. 실제 FLAC·AAC/M4A와 128 MiB보다 큰 유효한 FLAC(정상 PADDING 메타데이터를 희소 파일로 생성) 파형 대조. 전환 취소·캐시 재실행·자동 재생 없음 확인.
- 위 음원 검증은 로컬 개발 및 실제 Windows 0.1.5 패키지에서 모두 통과. 기존 삭제·드롭·이동·재생·업데이트를 포함한 통합 스크립트 8개 통과. 목록 대기와 드래그 핸들을 명시해 기존 재생목록 드래그 검사에서 발견한 타이밍 불안정도 수정.
- GitHub Windows·Mac 각각 59개 단위 검사·타입 검사·빌드, 통합 검증 67개 PASS 및 실제 설치 패키지의 긴 MP3·FLAC·AAC/M4A·큰 파일 파형 검증 통과. Mac 버튼 한 번의 실제 앱 교체·재실행·설정 보존도 통과: https://github.com/contentriumkorea/SONO/actions/runs/37086992557
- SONO 0.1.5 공개 완료, 설치 파일/메타데이터 8개 확인. 실제 공개 응답으로 Mac ZIP URL·크기·SHA-256 수용 및 Windows latest.yml 0.1.5 확인: https://github.com/contentriumkorea/SONO/releases/tag/v0.1.5
- 사용자 원본 음원/개인 Mac의 직접 확인은 하지 않았으며 합성 음원과 격리된 앱 데이터로 검사했습니다. 스트리밍 디코딩이 지원되지 않는 코덱은 기존의 제한된 Web Audio 호환 경로 또는 기본 재생바를 사용합니다.

## 0.1.4 위치 지정 가져오기·파형

- 위치 지정 삽입·빈 폴더·재생목록·중복 제외, 실제 PCM 샘플·스테레오 피크·무음·취소, 파형 캐시·원본 변경 무효화, PCM WAV 스트리밍 단위 검증 추가. 전체 55개 검사 로컬 통과.
- 실제 디스크 파일을 담은 Chromium 드롭으로 곡 아래·폴더 제목·빈 폴더·재생목록 위치에 삽입, 중복 파일의 위치 변경, 수동 순서·폴더 이름·재생목록 재실행 유지, 원본 파일 보존 통과.

- 기존 삭제·드롭·폴더 이동·페이드·재생·저장·업데이트 6개 통합 검증 로컬 통과. 새 기능 검증은 개발 및 실제 Windows·Mac 설치 패키지에서 모두 통과했습니다. 각 플랫폼에서 55개 단위 검사·타입 검사·빌드, 7개 통합 스크립트, 설치 패키지의 위치 추가·파형 검증 통과. Mac 실제 앱 교체·재실행·설정 보존도 통과했습니다: https://github.com/contentriumkorea/SONO/actions/runs/37085246699

- 탐색기/Finder에서 손으로 드래그하는 확인 및 개인 Mac 설치·실제 오디오 출력, WAV 외 코덱별 개별 파형 대조와는 구분합니다. Web Audio 분석 대상에서 128 MiB 또는 1시간을 넘거나 디코딩 불가능한 파일은 기본 재생바를 유지합니다.


## 0.1.3 자동 업데이트

- Mac 전용 다운로드·교체 도우미 구현. 크기·SHA-256·앱 ID·버전·코드 서명 검증 후 종료·교체·재실행하며 실행 확인 실패 시 기존 앱을 복구합니다.
- 새 단위 검증 10개: 다운로드·해시 오류·설치 준비 실패 후 재시도·잘못된 출처 차단, 실제 셸 도우미의 교체·실패 복구·기존 프로세스 종료 대기·경로 보호, 버튼 한 번의 다운로드→설치 및 다운로드 실패 시 설치 방지.
- 전체 48개 단위 테스트·타입 검사·빌드 로컬 및 GitHub Windows·macOS 환경 통과. 두 플랫폼의 기존 6개 통합 검증, Windows 패키지 한 번 클릭의 설치 호출, Mac 패키지 실제 자동 교체 검증도 모두 통과했습니다: https://github.com/contentriumkorea/SONO/actions/runs/36835010757
- Mac 통합 검증은 새 코드가 포함된 앱의 버전 정보만 0.1.2로 바꾼 격리된 시험 앱에서 실행합니다. 서버 응답만 로컬 ZIP으로 공급하고 버튼·IPC·ZIP 추출·서명 검증·앱 종료·실제 앱 교체·재실행·실행 확인·목록/설정 보존을 검증합니다. 실제 0.1.2의 수동 업데이트가 자동 교체로 바뀌었다는 의미는 아닙니다.
- 첫 Windows 배포 검사에서 셸 시험 앱의 실행 확인 대기 0.5초가 부족해 한 검사가 실패했습니다. 성공 시 기다리는 시험 시간을 5초로 늘린 뒤 양쪽 배포 검증이 모두 통과했습니다. 실제 앱의 실행 확인 시간은 30초입니다.
- SONO 0.1.3 공개 완료, 설치 파일·blockmap·업데이트 메타데이터 총 8개 자산 확인: https://github.com/contentriumkorea/SONO/releases/tag/v0.1.3
- 실제 공개 GitHub 응답으로 Mac 전용 업데이트 코드가 0.1.2→0.1.3을 인식하고 ZIP URL·크기·SHA-256을 받아들이며, Windows latest.yml이 0.1.3을 제공함을 확인했습니다.
- 0.1.2 이하 Mac 사용자는 이번에 최초 한 번 앱을 교체해야 합니다. 이후 버전부터 앱 안에서 자동 교체합니다. 개인 Mac에서의 직접 설치와 오디오 출력은 별도입니다.

- Mac 검증에서 다중 선택 및 전체 선택을 실제 Mac 단축키인 ⌘로 실행하고, 업데이트 모의 응답에 Mac 설치 파일을 포함하도록 테스트를 맞췄습니다.
- Windows·Mac 배포 환경에서 위 6개 통합 검증을 모두 통과한 뒤 공개하도록 배포 조건을 강화했습니다. 개인 Mac의 직접 설치·키보드 조작·실제 오디오 출력과는 구분합니다.

- 0.1.2 공개 완료, Mac DMG/ZIP·Windows EXE·blockmap·업데이트 메타데이터 총 8개 배포 자산 확인: https://github.com/contentriumkorea/SONO/releases/tag/v0.1.2

- 폴더 간 곡 이동·이름 변경 수정 후 Windows 패키지 검증 통과: 곡 하나만 다른 폴더로 이동, 여러 폴더에서 선택한 곡을 함께 이동, 마지막 곡 이동 후 빈 폴더 유지·다시 넣기, 폴더 묶음 순서 이동 시 곡 분류 유지, 파일 이름 표시·체크박스 칸 제거·아티스트 숨김, Ctrl 클릭 다중 선택, 곡·폴더 이름 변경과 재생 중 표시·미니 플레이어 반영, 재실행 후 이름·분류·빈 폴더·순서 저장 유지, 중복 가져오기 후 편집 유지, 원본 경로·파일 유지. `node scripts/organize-smoke.mjs --packaged`로 재현할 수 있습니다. 기존 재생·페이드·드롭·선택 삭제 패키지 검증도 통과했습니다.
- 재생 방식 설정 추가 후 Windows 패키지 검증 통과: 다음 곡 자동 재생, 대기열·셔플이 있어도 현재 곡을 반복, 현재 곡 종료 후 정지·대기열 유지, 정지 후 같은 곡 재생·직접 다음 곡 이동, 설정 변경 즉시 적용, 재실행 후 방식 복원·자동 재생 방지, 자동 재생의 목록 전체 반복 옵션 저장. 실제 WAV 종료 이벤트로 확인했으며 `node scripts/playback-smoke.mjs --packaged`로 재현합니다. 기존 재생 통합 검증도 통과했습니다.
- 빈 폴더 삭제 수정 후 Windows 패키지 검증 통과: 빈 폴더 개별 삭제, 기존 빈 폴더 일괄 정리, 곡이 있는 폴더 보호, 보관함 곡 삭제 시 빈 폴더 자동 제거, 재실행 후 삭제 유지, 원본 폴더·음악 파일 유지. `node scripts/organize-smoke.mjs --packaged`로 재현합니다. 기존 파일 드롭·곡 및 폴더 순서·페이드·다중 선택 삭제 통합 검증도 통과했습니다. 사용자 보관함의 빈 폴더 항목 18개를 정리했고 기존 5곡·재생목록·설정·재생 정보는 유지했으며, 정리 전 상태를 별도 파일로 백업했습니다.
- 탐색기와 실행 중 SONO의 무결성 수준은 모두 8192(일반 사용자)로 확인했습니다. 탐색기에서 직접 드래그하는 확인은 computer-use 자동 승인 검토가 SONO 창 조작을 허용하지 않아 수행하지 못했습니다. 자동 Chromium 파일 드롭 검증과 실제 탐색기 조작을 구분합니다.
- 실제 패키지 통합 검증: WAV 가져오기, 중복 제외, 재생 시간 진행, 일시정지, 탐색, 좋아요, 재생목록 생성/추가, 재생 대기열, EQ 조절, 미니 플레이어 조작, 취침 타이머 설정, 곡 종료 후 이동, 검색, 즉시 종료의 최종 위치 저장, 재실행 데이터 유지, 자동 재생 방지 통과.
- 초기 화면, EQ 화면 및 보관함을 1320×880 / 960×650 크기에서 확인.
- 테스트 음악과 데이터는 임시 폴더에 생성하고 검증 종료 후 제거했습니다. 실제 사용자 보관함에 예시 음악을 넣지 않았습니다.

미확인 항목: macOS 설치/실행/오디오 출력/미디어 키, WAV 외 코덱별 재생, 취침 타이머의 실제 15분 경과. 타이머 설정과 시간 계산은 구현되어 있으나 15분을 기다리는 검증은 수행하지 않았습니다.

macOS 공용 DMG/ZIP과 Windows NSIS 설치 파일을 GitHub Actions에서 빌드하여 v0.1.0 릴리스에 공개했습니다. Mac 실제 설치·실행·오디오 출력은 아직 확인하지 않았습니다.
