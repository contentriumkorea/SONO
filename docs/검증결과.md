# SONO 검증 결과

## 0.1.1 개별 삭제 수정

- Mac Delete 키에 해당하는 Backspace 입력이 선택한 곡을 삭제하지 않는 문제를 Windows Electron 환경에서 재현한 후 수정했습니다.
- `node scripts/delete-smoke.mjs` 통과: Backspace/Windows Delete 삭제, 곡 ‘⋯’ 메뉴에서 지정한 한 곡만 제거, 다른 선택과 재생 유지, 검색·이름 입력 중 삭제 방지, 재생목록에서만 제거, 현재 재생 곡 제거 시 정지, 저장·재실행 후 삭제 유지, 원본 음원 유지.
- 기존 38개 단위 테스트·타입 검사·빌드 및 드롭·페이드·정리 통합 검증 통과.
- GitHub Actions에서 Windows와 macOS 양쪽의 개별 삭제 통합 검증을 배포 조건으로 추가했습니다. 개인 Mac의 실제 키보드 조작·설치 검증과 구분합니다.

## 0.1.0 기존 검증

2026-10-01, Windows에서 검증했습니다.

- 단위 테스트: 9개 파일, 38개 테스트 통과.
- TypeScript 타입 검사 및 제품용 빌드 통과.
- Windows 패키징 완료: `release/win-unpacked/SONO.exe`.
- 드래그앤드롭 수정 후 Windows 패키지에서 실제 디스크 파일을 담은 Chromium 드롭 이벤트로 검증: 여러 WAV 파일, 사이드바 드롭, 중복 제외, 하위 폴더 탐색, 지원하지 않는 파일 안내, 페이지 이동 방지, 드롭 안내 표시·창 밖으로 나갔을 때 닫기, 저장 통과. `node scripts/drop-smoke.mjs --packaged`로 재현할 수 있습니다. 탐색기/Finder에서 손으로 드래그하는 검증은 별도입니다.
- 사용자 정정 반영 후 Windows 패키지에서 검증: 별도 폴더 탐색 화면 대신 보관함 목록의 폴더 제목 아래 해당 곡 표시, 제목 옆 버튼 제거, 왼쪽 버튼 하나로 재생·일시정지·4초 위치에서 이어듣기, 같은 폴더 안의 곡 순서 드래그, 재생목록의 서로 다른 폴더 곡 순서 드래그, 재실행 후 순서·폴더 표시·좋아요 유지, 960×650 화면의 사이드바·목록 표시 통과. 기존 재생 통합 검증도 다시 통과했습니다.
- 페이드·드래그·선택 삭제 수정 후 Windows 패키지 검증 통과: 실제 Web Audio GainNode의 페이드 인·아웃 값 변화, 페이드 아웃 중 재생 재개 시 정지 예약 취소, 곡 전환 도중 일시정지해도 새 곡 소스 유지, 설정 저장·복원, 손잡이로 곡·폴더 묶음 이동, 드래그 취소 후 파일 드롭, Shift 다중 선택, 전체 선택·Delete, 재생목록에서만 제거, 보관함 삭제 시 관련 재생목록·재생 상태 정리, 재실행 후 삭제 유지. 테스트 원본 WAV 파일이 삭제되지 않았음을 확인했습니다.
- 폴더 간 곡 이동·이름 변경 수정 후 Windows 패키지 검증 통과: 곡 하나만 다른 폴더로 이동, 여러 폴더에서 선택한 곡을 함께 이동, 마지막 곡 이동 후 빈 폴더 유지·다시 넣기, 폴더 묶음 순서 이동 시 곡 분류 유지, 파일 이름 표시·체크박스 칸 제거·아티스트 숨김, Ctrl 클릭 다중 선택, 곡·폴더 이름 변경과 재생 중 표시·미니 플레이어 반영, 재실행 후 이름·분류·빈 폴더·순서 저장 유지, 중복 가져오기 후 편집 유지, 원본 경로·파일 유지. `node scripts/organize-smoke.mjs --packaged`로 재현할 수 있습니다. 기존 재생·페이드·드롭·선택 삭제 패키지 검증도 통과했습니다.
- 재생 방식 설정 추가 후 Windows 패키지 검증 통과: 다음 곡 자동 재생, 대기열·셔플이 있어도 현재 곡을 반복, 현재 곡 종료 후 정지·대기열 유지, 정지 후 같은 곡 재생·직접 다음 곡 이동, 설정 변경 즉시 적용, 재실행 후 방식 복원·자동 재생 방지, 자동 재생의 목록 전체 반복 옵션 저장. 실제 WAV 종료 이벤트로 확인했으며 `node scripts/playback-smoke.mjs --packaged`로 재현합니다. 기존 재생 통합 검증도 통과했습니다.
- 빈 폴더 삭제 수정 후 Windows 패키지 검증 통과: 빈 폴더 개별 삭제, 기존 빈 폴더 일괄 정리, 곡이 있는 폴더 보호, 보관함 곡 삭제 시 빈 폴더 자동 제거, 재실행 후 삭제 유지, 원본 폴더·음악 파일 유지. `node scripts/organize-smoke.mjs --packaged`로 재현합니다. 기존 파일 드롭·곡 및 폴더 순서·페이드·다중 선택 삭제 통합 검증도 통과했습니다. 사용자 보관함의 빈 폴더 항목 18개를 정리했고 기존 5곡·재생목록·설정·재생 정보는 유지했으며, 정리 전 상태를 별도 파일로 백업했습니다.
- 탐색기와 실행 중 SONO의 무결성 수준은 모두 8192(일반 사용자)로 확인했습니다. 탐색기에서 직접 드래그하는 확인은 computer-use 자동 승인 검토가 SONO 창 조작을 허용하지 않아 수행하지 못했습니다. 자동 Chromium 파일 드롭 검증과 실제 탐색기 조작을 구분합니다.
- 실제 패키지 통합 검증: WAV 가져오기, 중복 제외, 재생 시간 진행, 일시정지, 탐색, 좋아요, 재생목록 생성/추가, 재생 대기열, EQ 조절, 미니 플레이어 조작, 취침 타이머 설정, 곡 종료 후 이동, 검색, 즉시 종료의 최종 위치 저장, 재실행 데이터 유지, 자동 재생 방지 통과.
- 초기 화면, EQ 화면 및 보관함을 1320×880 / 960×650 크기에서 확인.
- 테스트 음악과 데이터는 임시 폴더에 생성하고 검증 종료 후 제거했습니다. 실제 사용자 보관함에 예시 음악을 넣지 않았습니다.

미확인 항목: macOS 설치/실행/오디오 출력/미디어 키, WAV 외 코덱별 재생, 취침 타이머의 실제 15분 경과. 타이머 설정과 시간 계산은 구현되어 있으나 15분을 기다리는 검증은 수행하지 않았습니다.

macOS 공용 DMG/ZIP과 Windows NSIS 설치 파일을 GitHub Actions에서 빌드하여 v0.1.0 릴리스에 공개했습니다. Mac 실제 설치·실행·오디오 출력은 아직 확인하지 않았습니다.

## 업데이트 및 배포 검증

- 새 버전 확인, 중복 클릭, 명시적 다운로드·설치, 다운로드 진행률, 실패 후 재시도, 설치 전 상태 저장 실패 시 설치 방지, 버전 비교 및 릴리스 URL·설치 파일 검증: 7개 테스트 통과.
- 개발 실행과 실제 Windows 배포 패키지에서 업데이트 버튼·현재 버전·확인 중·새 버전·다운로드 진행률·재시작 버튼 UI 및 IPC 통과. 서버 응답과 다운로드는 테스트에서 모의 처리했으며 실제 새 버전 교체 설치와 구분합니다.
- 로컬 NSIS 설치 파일, blockmap, latest.yml 및 GitHub 공급자 app-update.yml 생성 완료 (`release/github/`). 기존 실행 중 앱과 다른 출력 폴더를 사용했습니다.
- 음원 폴더 이동·이름 변경·순서·다중 선택·재시작 저장·빈 폴더 정리 검증 통과.
- 설치 EXE의 SHA-512를 latest.yml과 대조합니다. 사용자 데이터나 음원은 배포 파일에 포함하지 않습니다.
- Mac 첫 배포는 수동 교체 업데이트이며 앱 내 자동 설치는 제공하지 않습니다.
