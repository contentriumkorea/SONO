# SONO

개인용 로컬 음악 플레이어. macOS와 Windows를 위한 Electron 앱입니다.

## 실행

Windows에서 `SONO 실행.cmd`를 더블클릭합니다. 개발용 실행에는 Node.js와 설치된 프로젝트 의존성이 필요합니다. 이 작업 환경의 실행 파일은 `release/win-unpacked/SONO.exe`에 생성됩니다.

개발 환경에서는 다음 명령을 사용합니다.

```sh
pnpm install
pnpm dev
```

제품용 코드 빌드 및 실행:

```sh
pnpm build
pnpm start
```

## 사용법

- 음악 추가 메뉴에서 파일이나 폴더를 가져옵니다. 원본 파일은 이동하거나 복사하지 않습니다.
- 탐색기/Finder의 음악 파일이나 폴더를 곡 위·아래나 폴더 제목에 놓으면 그 위치에 추가합니다. 재생목록에서도 원하는 위치에 넣을 수 있으며 이미 가져온 파일은 중복 없이 위치를 바꿉니다. 목록 외 공간에 놓으면 기본 가져오기를 사용합니다. 여러 파일과 하위 폴더를 처리하며 이미 가져온 곡은 중복 추가하지 않습니다.
- 보관함 목록은 ‘폴더 이름 → 그 아래 곡들’ 형태로 표시합니다. 하위 폴더의 음악은 해당 하위 폴더 이름 아래에 모입니다.
- 파일 이름을 클릭하면 선택하고, 더블클릭하면 재생합니다. 하단에서 반복·셔플·탐색·음량을 조절합니다.
- 하단 다음 곡 버튼 오른쪽의 재생 방식 아이콘에서 ‘다음 곡 자동 재생 / 한 곡 반복 / 현재 곡만 재생 후 정지’를 선택합니다. 자동 재생에서는 목록 끝에서 처음부터 반복하는 옵션도 있습니다. 한 곡 반복·재생 후 정지는 대기열이나 셔플보다 우선하고, 직접 누르는 이전·다음 버튼은 사용할 수 있습니다. 선택한 방식은 자동 저장됩니다.
- 곡 왼쪽 버튼 하나로 재생·일시정지합니다. 다시 누르면 멈춘 위치에서 이어 듣습니다.
- 곡 왼쪽의 점 모양 손잡이를 끌어 순서를 바꿉니다. 폴더 제목의 손잡이로 폴더 묶음도 이동할 수 있습니다. 곡을 다른 폴더 제목이나 그 안의 곡에 놓으면 해당 폴더로 옮깁니다. 빈 폴더에도 다시 넣을 수 있고, 재생목록에서는 곡을 자유롭게 정렬합니다. 정한 순서는 자동 저장됩니다.
- Ctrl/⌘ 클릭·Shift 클릭으로 여러 곡을 선택하고 ‘선택 삭제’ 또는 Delete를 누릅니다. Ctrl/⌘+A로 현재 표시된 곡을 모두 선택할 수 있습니다. 보관함에서 삭제하면 재생목록·대기열에서도 제거합니다. 재생목록에서 삭제하면 해당 목록에서만 제거합니다. 원본 파일은 삭제하지 않습니다.
- 폴더 제목 오른쪽 연필 버튼, 곡의 더 보기 → 이름 변경으로 SONO에 표시할 이름을 바꿉니다. 목록에는 메타데이터 제목·아티스트 대신 파일 이름을 표시합니다. 폴더 이동·이름 변경은 SONO 안에서만 적용하며 원본 파일과 경로는 유지합니다.
- 빈 폴더 오른쪽 휴지통으로 해당 항목을 삭제하고, 상단 ‘빈 폴더 정리’로 모두 지웁니다. 보관함에서 곡을 삭제하면 빈 폴더 항목도 자동 정리합니다. 원본 파일·폴더는 유지합니다.
- 하단의 페이드 설정에서 페이드 인·아웃을 각각 0~5초로 조절합니다. 기본값은 0.35초이고 0초는 끄기입니다. 시작·이어듣기, 일시정지·곡 전환, 곡 끝에 적용됩니다.
- 하트로 좋아하는 곡을 모읍니다.
- 왼쪽의 + 버튼으로 재생목록을 만들고, 곡의 더 보기 메뉴에서 목록에 추가합니다.
- 재생목록의 더 보기 메뉴로 곡 순서를 바꿀 수 있습니다. 목록 순서 정렬에서만 활성화됩니다.
- 음악 추가 메뉴에서 M3U 목록을 가져오고, 재생목록 상단의 내려받기 버튼으로 내보냅니다.
- 곡의 더 보기 또는 재생바의 가위 버튼에서 **음원 길이 조정**을 열 수 있습니다. 시작·종료 시간, 슬라이더, 현재 위치 버튼으로 지정한 구간만 재생하며 구간 끝에서 자동 넘김·한 곡 반복·정지가 적용됩니다. 목록/재생바 길이와 파형도 구간 기준으로 표시합니다. 설정은 재실행 후 유지되고 **원래 길이**로 복원할 수 있습니다. 음원 원본을 변경하거나 새 오디오 파일을 저장하는 기능은 아닙니다.
- 재생바는 실제 음원의 파형을 흰색·회색으로 표시합니다. 클릭·드래그·방향키로 탐색할 수 있고 분석 결과는 자동 저장합니다. 원본 파일 변경 시 다시 분석합니다. PCM WAV와 MP3·FLAC·M4A/AAC 등 지원 코덱은 파일을 나누어 분석하므로 긴 파일도 파형이 표시됩니다. 분석 중에는 진행률과 지금까지 읽은 파형이 표시되고, 곡을 바꾸면 분석을 취소합니다. 스트리밍 디코딩을 지원하지 않는 형식은 짧은 파일에 한해 Web Audio 호환 경로를 사용하며, 디코딩 불가능한 파일은 기본 재생바를 유지합니다.
- 하단 EQ 버튼에서 20밴드 EQ와 프리앰프를 조절합니다. 사용자 조절값은 자동 저장됩니다.
- 상단의 작은 창 버튼으로 미니 플레이어를 엽니다. 본 창과 같은 재생 엔진을 제어합니다.
- 하단 타이머에서 15·30·45·60·90분 뒤 재생을 멈추도록 설정합니다. 타이머는 앱 실행 동안만 유지됩니다.
- Space: 재생/일시정지. Ctrl(맥은 ⌘)+좌우 방향키: 이전/다음 곡.

보관함, 좋아요, 재생목록, 음량, EQ, 최근 곡과 위치는 앱 데이터 폴더에 저장합니다. 앱을 다시 실행해도 음악은 자동 재생하지 않습니다. 저장 오류 시 이전 백업을 읽으며 손상된 파일은 보존합니다. 음악을 다른 폴더로 옮겼다면 새 위치에서 다시 가져와야 합니다.

## 검증

```sh
pnpm test
pnpm typecheck
pnpm build
node scripts/smoke.mjs
node scripts/drop-smoke.mjs
node scripts/organize-smoke.mjs
node scripts/playback-smoke.mjs
```

통합 검증은 임시 데이터 폴더와 프로그램으로 만든 WAV 파일을 사용합니다. 실제 보관함에 예시 음악을 넣지 않습니다. 스크린샷과 검증 로그는 `test-results`에 생성합니다.

## 플랫폼과 현재 범위

Windows에서 실제 실행 및 파일 재생을 검증합니다. macOS용 소스와 패키징 설정을 제공하지만 macOS 실행 및 오디오 출력은 별도 맥에서 확인해야 합니다.

MP3, WAV, FLAC, M4A/AAC, OGG/Opus, AIFF 파일을 가져오도록 구성했습니다. 실제 재생 가능 여부는 코덱과 컨테이너에 따라 다르며 지원하지 않는 파일에는 오류를 표시합니다. DRM, AIMP 전용 스킨·플러그인, 파일 변환·CD 추출·CUE 분리는 현재 범위에 포함하지 않습니다.

GitHub Releases에서 Windows 설치 파일과 Mac 공용 설치 파일을 배포합니다. 왼쪽 아래 업데이트 버튼으로 새 버전을 확인합니다. Windows·Mac 설치 버전은 ‘지금 업데이트’ 한 번으로 다운로드·앱 교체·재실행합니다. Mac 0.1.2 이하에서는 0.1.3으로 최초 한 번 직접 교체한 뒤 이후 자동 업데이트를 사용합니다. 음악 재생은 로컬 파일을 사용하며 업데이트 확인 시에만 GitHub에 연결합니다.

## 로컬 패키징

```sh
pnpm release:win
# macOS에서 실행
pnpm release:mac
```

GitHub Actions는 Windows NSIS 설치 파일과 Mac 공용 DMG/ZIP을 빌드합니다. macOS는 ad-hoc 서명을 사용하는 시험 배포이며 Developer ID 서명·공증은 아직 구성하지 않았습니다. Mac 자동 업데이트는 파일 검증과 실패 시 복구를 포함합니다. 상세 절차는 배포와 업데이트 안내를 확인하세요.
