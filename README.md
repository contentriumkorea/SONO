# MusicBoard 업데이트 호환 주소

**공식 소스 코드와 새 배포: [contentriumkorea/MusicBoard](https://github.com/contentriumkorea/MusicBoard)**

이 저장소는 예전 SONO 주소를 사용하는 설치 앱의 업데이트 연결을 유지합니다.
MusicBoard의 공개 배포 파일을 크기·SHA-256 검증 후 동일하게 제공합니다.
앱 개발과 이슈 등록은 위 MusicBoard 저장소를 이용해주세요.

워크플로는 공개된 최신 정식 배포를 주기적으로 확인하며 이미 같은 배포가 있으면 변경하지 않습니다.
